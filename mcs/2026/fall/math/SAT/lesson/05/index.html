Core · 10–35 minutes
Core Concept

A Solution Is a Shared Truth

Start with the graph
Each equation permits every point on its own line. The system permits only points accepted by both equations. Where can that happen?
Equation 1 is trueANDEquation 2 is true
The word and is the whole topic: a system solution is an ordered pair, not two unrelated values.

Substitution with a Protected Sign

DEMO ALevel 2

2x-y=4
STEP 1Replace y

STEP 2Distribute the negative

Method 2

Elimination: Engineer a Cancellation

Add when opposites are ready
3x+2y=17
5x-2y=7

The y-terms cancel immediately.
Scale when cancellation is hiding
2x+3y=11
5x+6y=28

Multiply the first equation by -2 to create opposites.
Conservation rule
If you multiply an equation, every term—including the constant—must be multiplied.

Core · 10–35 minutes
Coefficient Detector

Proportions Reveal the Geometry

No solution
A₁/A₂ = B₁/B₂
but C₁/C₂ differs
The variable coefficients scale together, but the constants do not.
Infinitely many solutions
A₁/A₂ = B₁/B₂ = C₁/C₂
Every coefficient and constant shares one scale factor.
Fast-test trap
Do not compare only the x-coefficients. Ask whether one entire equation is a multiple of the other.
Core · 10–35 minutes
Difficult Example 2

Parameter Problem: Force No Solution

DEMO CLevel 4
For what value of k does the system have no solution?
6x+ky=15
2x-3y=8
STEP 1Match the x-scale
6/2=3

The first left side must be three times the second.

STEP 2Impose the y-scale
k=3(-3)

This makes the lines parallel.

STEP 3Check constants differ
15 ≠ 3(8)

Finish the one-step arithmetic for k; distinct constants confirm no solution.

The numerical value of k is left for students to complete.

Absolute Value

Distance Creates Two Linear Cases

|L(x)|=c
L(x)=cORL(x)=-c
Absolute value asks for distance from zero. If the distance is positive, the inside can point in either direction.
Gatekeeper
If c<0, there are no real solutions. A distance cannot be negative.

Absolute Value as Two Linear Cases

DEMO DLevel 3

Bonus · Level 5

Nested Cases and an Optimization

B4Level 5Four-case system
Real numbers x and y satisfy
|x-2y|=7
|2x+y|=11
What is the greatest possible value of 3x-y?
Case map
x-2y=±7
2x+y=±11
The signs vary independently, creating up to four systems.
Optimization finish
For each surviving ordered pair, evaluate 3x-y. The largest expression value—not the largest x—wins.
