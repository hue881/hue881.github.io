A reflection, not a memorized trick

Why the Sign Reverses

The mirror rule

Multiplying or dividing both sides by a negative reverses order. On the number line, every value reflects across 0, so “left of” becomes “right of.”

If a < b, then −a > −b.
Reason first
If −6x > 24, should x be positive or negative? Which familiar value could test your prediction?

Two Variables: Draw the Border First

2x + 3y ≤ 12

Boundary protocol

  1. Replace the inequality with equality.
  2. Draw the boundary: solid for ≤ or ≥; dashed for < or >.
  3. Test one point not on the line.
  4. Shade only the side that passes.

Read Roots from Coefficients

For roots r and s

r + s = −b/a
rs = c/a

Gatekeeper
