# Digital SAT Math — Saturday Program Syllabus (Subject to revision)
**Fall 2026 – Spring 2027 | 80 minutes per session | 34 total sessions**

## 1. Program Overview

| Item | Detail |
|---|---|
| Meeting time | Saturdays, 80 minutes |
| Fall term | 9/19/26 – 12/19/26 (13 sessions; no class 11/28) |
| Spring term | 1/2/27 – 6/26/27 (21 sessions; no class 2/6, 2/13, 4/24, 5/1, 5/29) |
| Section modeled | Digital SAT Math: 44 questions, two 35-minute adaptive modules (22 questions each, 2 unscored) |
| Domain weighting targeted | Algebra ~35%, Advanced Math ~35%, Problem-Solving & Data Analysis ~15%, Geometry & Trigonometry ~15% |
| Question formats | ~75% multiple choice, ~25% student-produced response (SPR) |
| Tools | Bluebook practice tests, embedded Desmos graphing calculator (permitted on the entire Math section), reference sheet, student error log |
| Anchor test dates | Dec 5, 2026; Mar 6, 2027; May 1, 2027; Jun 5, 2027 |

### Session template (80 minutes)
1. 0–10 min — Warm-up: 4 questions drawn from last week's error log (mixed difficulty).
2. 10–40 min — Direct instruction on the day's skill cluster, with worked Module-2-level examples.
3. 40–65 min — Timed drill: 10–12 questions at test pace (~1:35/question), calculator-optional split.
4. 65–75 min — Debrief: answer-choice autopsy, Desmos alternative solution paths, SPR entry rules.
5. 75–80 min — Homework assignment + error-log entry.

### Standing expectations
- Homework: 30–45 questions per week (one skill set + one mixed set), logged in the shared tracker.
- Error log: every missed question classified as *content gap*, *process slip*, *misread*, or *timing*.
- Full-length Math sections: 5 across the year (9/19, 12/19, 4/10, 5/22, 6/19).
- Domain checkpoints: 22-question single-module quizzes after each domain block.


## 2. Fall Term — Diagnostic, Algebra, and Data Analysis

Fall builds the two highest-yield foundations: Algebra (largest domain) and Problem-Solving & Data Analysis.

## 4. Assessment and Reporting

| Instrument | Frequency | Purpose |
|---|---|---|
| Full-length Math section | 5 total (9/19, 12/19, 4/10, 5/22, 6/19) | Scaled-score trajectory and stamina under adaptive conditions |
| Domain checkpoint module | 5 total (10/31, 12/12, 3/6, 4/3, plus labs) | Confirm mastery before moving to the next domain |
| Weekly warm-up | Every session | Spaced retrieval of previously missed items |
| Error log audit | Monthly | Distinguish content gaps from process and timing errors |
| Parent/student progress report | End of each term (12/19, 6/26) | Score movement by domain, homework completion, next steps |

**Mastery bar for advancing a domain:** ≥80% accuracy on the checkpoint module with no more than one timing-driven error.

## 5. Calendar Notes and Flags

- **9/19 timing:** a complete digital SAT runs about 2 hours 14 minutes, so the 80-minute slot fits the full adaptive **Math section (70 min)** plus setup. The Reading & Writing section is assigned as a proctored take-home if a total-score baseline is needed.
- **Class days that collide with national SAT dates:** 12/5/26, 3/6/27, and 6/5/27. Each has an asynchronous make-up path built in; 5/1/27 (SAT date) is already a scheduled no-class Saturday.
- **Longest gap:** 1/30 → 2/20 (three weeks, spanning the 2/6 and 2/13 closures). This lands mid–Advanced Math, so an independent problem set plus a midweek virtual check-in is scheduled.
- **Peak windows:** content coverage completes 4/3, leaving nine sessions of testing, error analysis, and pacing work ahead of the June 5 administration.
