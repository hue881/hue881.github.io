🐛 Key Vocabulary

Bugs are not failures — they're clues

bug

tap for the meaning

A mistake in code that makes a program do something different from what you planned.

debugging

tap for the meaning

The process of finding and fixing a bug — one careful step at a time.

🦋 Why do we call it a "bug"? (click to find out)

The word "bug" comes from a real moth found stuck inside a giant 1947 computer, causing it to malfunction! Ever since, programmers call mistakes in code "bugs."

A bug never means you're bad at coding. It means you're one clue away from understanding your program better.

🔍 Our Debugging Method

Stop → Check → Find → Fix → Test (tap each step)

1
Stop

Don't panic or randomly change things. Take a breath.

2
Check

What should happen? What is actually happening?

3
Find

Look line by line where the behavior first goes wrong.

4
Fix

Change one thing at a time — never many things at once.

5
Test

Run it again. Did it work? If not, go back to Check.

Repeat until it works. That's debugging!

💡 A Debugging Superpower

"Print debugging" — the fastest fix in your toolkit

If you're not sure a variable holds the value you expect, just ask the program to show you.

score = 0 score = score + 1 print("score is now:", score) # check it!

Drag a "say [variable] for 2 seconds" block right after the spot you suspect is buggy.

Or turn on the checkbox next to a variable in the palette to watch it live on stage.

Question: if your variable shows the wrong number, does that tell you WHERE the bug is, or just THAT there is one?

🔎 Know Your Enemy

Three kinds of bugs to hunt for (tap to flip)

🚫 Syntax Bug

tap to reveal

The computer can't even understand your code — like a typo or a missing colon.

Program won't run at all.

💥 Runtime Bug

tap to reveal

The code is written correctly, but it crashes while running — like dividing by zero.

Program starts, then stops suddenly.

🤔 Logic Bug

tap to reveal

The program runs perfectly — it just does the wrong thing, like adding instead of subtracting.

Hardest to find — no error message!

Which of these three do you think is hiding in your project right now?
