Find Your Tier and Complete Your Goal
Tier A — Foundations · Grades 1–3
🆎 Goal: Make your one feature run without help

Open your project. Run it 3 times in a row. If it breaks, try ONE fix using Stop → Check → Find → Fix → Test.

  • I ran my project 3 times
  • It worked the same way every time (or I know why it didn’t)
  • If it broke, I tried ONE fix, not many at once

    • Did your project work all 3 times? What happened?

    Tier B — Core · Grades 3–5
    ✅ Goal: Core feature runs end-to-end, one bug logged

    Get your must-have feature fully working. If you hit a bug, write it in the log below using the 5-step method.

  • Core feature runs from start to finish tonight
  • I used print/say debugging at least once
  • I logged one bug below, even if I couldn’t fully fix it

    • Bug Log — Stop / Check / Find / Fix / Test:

    Tier C — Accelerated · Grades 6–9
    🟣 Goal: Core feature solid + edge-case stress test

    Finish your core feature, then deliberately try to break it with 2 unusual inputs. Log both attempts.

  • Core feature runs reliably
  • Tried 2 edge-case inputs on purpose
  • Classified any bug found (syntax/runtime/logic)

    • Edge-case test log:

    💬 Part 2 · Showcase Intro Draft (10 min)
    Start Your “What It Does” Description
    🎤 Get Ready to Explain Your Project

    On the last day of Build (Session 22), you’ll write a 30-second spoken intro for the showcase. Tonight, get the raw material down — it doesn’t need to be perfect.

    1. In one sentence, what is your project?

    2. How does someone use it? (What do they click, type, or do first?)

    3. What is the ONE thing you're most proud of in your project?

    Say your 3 sentences out loud once before bed — it’s easier to remember than reading it silently!
