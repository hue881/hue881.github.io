💻 Part C
Read the code — then explain it like a teacher

The final asks students not just to run code mentally, but to name the concepts used. These prompts build that skill directly.

Prompt 1 · Conditionals
secret = 7
guess = 9
if guess > secret:
    print("Lower")
else:
    print("Higher")

What prints?

Which concept does this use?

Prompt 2 · Chatbot keyword rule
msg = "hello robot".lower()
if "hello" in msg:
    print("Hi there!")
else:
    print("I don't understand yet.")

What prints?

Why does lower() help?

Prompt 3 · Lists + functions + counting
def count_cats(items):
    total = 0
    for animal in items:
        if animal == "cat":
            total = total + 1
    return total

print(count_cats(["cat", "dog", "cat", "bird"]))

What prints?

Name 3 concepts you see

Teacher move: ask students, “Which single line shows the decision?” and “Which line stores changing information?” That often unlocks the whole explanation.
🤖 Part D
Explain AI, training data, and bias

This is the heart of the final concept check. Keep the language age-appropriate and concrete.

Use examples, not just big words

1. What is AI?

2. What is training data? Use a simple example.

3. Why can AI be wrong or unfair?

4. What should a human do before trusting an AI answer?

Concrete story prompt: “If a model only saw sunny playground photos, what might happen on a rainy day?” This helps students explain bias without using abstract adult language.

Tiered rehearsal checklist
Tier A
  • I can show the start of my project.
  • I can point to one loop or one if-decision.
  • I can explain one tiny turtle or Python idea too.
Tier B
  • I can explain what my project does.
  • I can name at least two concepts it uses.
  • I can say what I still want to improve.
Tier C
  • I can show a working Python component.
  • I can explain the code logic clearly.
  • I can justify why my AI feature counts as AI.
Best partner-demo script: what it does → what concept it uses → where the AI part is → one thing I fixed or still want to build.
🛠️ Part F
Bug hunt — final-project problems you can actually fix

1My project starts but nothing reacts.

2My chatbot always says “I don't understand.”

3The score or variable never changes.

4My model guesses badly on new examples.

Useful coaching prompts: “Where is the start event?” “What exact word is your rule checking for?” “Does the variable ever get updated?” “Did the model see enough varied examples?”
