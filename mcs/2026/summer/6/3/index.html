Today’s Plan

How build day flows

1
Warm start
Reopen project plan, name the smallest thing that can work today, and start quickly.
2
Build sprint
Students code first, not perfect first: title screen, one scene, one rule, one response, or one trained model.
3
Teacher conferences
Each student gets a quick check-in: what works, what is stuck, and what the next move should be.
4
Mid-build AI check
Students explain where the AI, data, or decision-making idea appears in their project.

Build Strategy

What counts as a first working slice?

Game track

One playable loop: start, move, click, score, or win/lose rule.

AI mini-app

One real response path: classify two things, answer one keyword, or make one prediction.

Story track

One scene that runs: character appears, dialogue works, and one choice changes what happens.

Teacher prompt: “If your project were only 20 seconds long today, what would we still be able to test?”

Tap a build lens

Start with one thing the class can test without explanation.

Conference Moves

Short questions that move projects forward

Ask first

  • What already works on your screen?
  • What part is almost working?
  • What is the one bug or blocker?

Then narrow it

  • What is the next tiny test?
  • Can we fake a simpler version first?
  • What can wait until Build Day 2?

Quick conference check

Click a conference question to reveal the teaching move.

Conference script

1. Show me the working part
2. Name the stuck part
3. Pick one next step
4. Build for 5 more minutes before changing the plan

AI Check

Where is the AI, data, or decision?

Decision logic

If the player touches lava, lose a life. If the guess is too high, say “too high.”

Data

A list of words for a chatbot, examples for Teachable Machine, or saved score values.

AI element

A classifier, chatbot behavior, prediction, confidence score, or an explainable “smart” choice.

Mini check-in

Choose a statement to check whether it counts as AI, data, or decision logic.

Student sentence stem: “My project uses AI or AI-style logic when it ________ using ________.”

Video 2

Debugging is part of building

YouTube source

Look for these habits

  • Read what happened, not what you hoped happened.
  • Change one thing, then test again.
  • Ask: where did the program stop doing what I expected?

Build-day reminder: a bug is evidence that your project is becoming real.

Share-Out

End-of-class reflection

Pair share

Show the part that works. Then name the one thing you will fix or add for homework.

Exit prompts

  1. My first working slice is…
  2. The AI, data, or decision part is…
  3. The thing I am stuck on is…

Homework: get one part working and write down one thing that is still stuck so the class can fix it together next time.
