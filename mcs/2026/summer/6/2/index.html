Concept Check

Read the code like a detective

score = 0
for turn in range(3):
    answer = input("Type yes or no: ")
    if answer == "yes":
        score = score + 1
print(score)

Ask yourself

  • Which line stores memory for the program?
  • Which part repeats?
  • Which part makes a decision?
  • If the user types yes, no, yes — what prints at the end?

Teacher move: ask students to point, name, and explain before giving any answer.

Demo Prep

A simple demo script students can follow

  1. Say your project name and what it is for.
  2. Show the main action: click, type, play, or test.
  3. Point to one key piece of code or one important Scratch stack.
  4. Explain one coding idea inside it: loop, variable, conditional, function, list, or event.
  1. Name one AI idea in the project, or explain how the project connects to AI.
  2. Say one thing that already works well.
  3. Say one thing you still want to improve.
  4. End with: “The next thing I will build is …”

Interactive Practice

Turn code into speaking prompts

def describe_project(name, feature):
    print("My project is " + name)
    print("One cool feature is " + feature)

describe_project("Cat Maze", "a timer")

Teacher prompts

  • What stays the same every time this function runs?
  • What changes between calls?
  • How is this like a student using the same demo structure but swapping in a different project name and feature?

Movement Break · 5 minutes

Debug your body, too

Stand up and act out a mini algorithm with a partner: clap, turn, point, freeze. Then repeat it. Now change only one step. Which part was the “same code,” and which part was the “new input”?

Differentiation

Three lanes, same destination

Tier A

Scratch capstone is okay, plus one tiny turtle program. Focus on clear explanation of events, loops, variables, and what the project does.

Tier B

Main track. Show a project with at least one real coding idea and explain one AI connection or one fairness idea clearly.

Tier C

Must show a working Python component. Stretch: explain a function, list, or smarter game behavior, not just surface features.

Feedback Language

Private, encouraging feedback stems

Notice
I can see your project already does ____. That tells me you understand ____.
Nudge

Next move

Clarify

Explain

Celebrate
You stuck with a hard bug and kept going. That matters.
