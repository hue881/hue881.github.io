One partner thinks of an animal. The other asks only yes/no questions to guess it in 20 tries or fewer.

1. What animal did your partner guess (or were you guessing)?

2. Write 3 of the yes/no questions that were asked:

3. What if the guesser could only react to specific words like “has fur” or “lives in water”? Would a fixed list of rules be enough to win?

🤖 Big Idea

A chatbot that only reacts to keywords is playing a version of this exact game — it just checks your words against a list of rules it already knows. That’s what we build today!

Keep this in your head as we go: rules in, rules out. Nothing magical — just a very organized list of “if this, then that.”
💡 Part 2 · Mini-Lesson (15–20 min)
What Actually Makes a Chatbot “Talk”?
✅ Four Ingredients, One Conversation

Check each ingredient off as your teacher explains it, then match it to what it does:

Look at this tiny conversation. Which ingredient makes each line possible?

hi there!
Hello! I'm PyBot. Ask me anything!
what's your name
I'm PyBot, a simple Python chatbot.
This is a rule-based chatbot: it checks your typed words for keywords like “hi” or “name,” then picks a pre-written reply. No learning happens — we wrote every rule.
🔍 The Trick: Keywords Inside a Sentence

The in keyword searches text for a smaller piece:

"hello" in "well hello there"  # → True

Always lowercase first so “HELLO,” “Hello,” and “hello” all match:

msg = input("You: ").lower()

Question for later: What happens if a message has TWO keywords at once, like “hi, how are you”? Which rule wins?

🤖 AI Moment — Rules We Wrote vs. Patterns a Model Learned

Our chatbot today

Follows rules WE wrote. Every response is something a human typed in advance. No surprises, fully explainable.

A real chatbot (LLM)

Predicts the next word using patterns learned from billions of examples. Nobody wrote a rule for every reply — it was trained, not programmed.

In your own words: why can an LLM say things nobody ever typed, but our bot can’t?

🔨 Part 3 · Guided Build (20 min)
Build a Keyword Chatbot — Step by Step

Follow along with your teacher in Python Playground. Check off each step as you complete it.

🛠 5-Step Build Checklist
Step 1 — Greet the human
print("Chatbot: Hi! Type 'bye' to exit.")
Step 2 — Start a loop & get lowercase input
while True:
  msg = input("You: ").lower()
Step 3 — Check for the exit word first
if "bye" in msg:
  print("Goodbye!"); break
Step 4 — Add keyword rules with elif
elif "hello" in msg or "hi" in msg:
  print("Hi there!")
elif "name" in msg:
  print("I'm PyBot!")
Python checks rules top to bottom and stops at the FIRST match — order matters!
Step 5 — Catch everything else
else: print("I don't understand yet.")

Try these 4 messages on your bot and write what it says:

🔍 Code Detective — Find the Bug

This bot never says hello — why? Read line by line and circle the buggy line.

1  msg = input("You: ")
2  if "Hello" in msg:
3    print("Hi there!")
4  else: print("?")

Which line is the bug, and why?

Hint: We forgot .lower() on line 1 — the user types “hello” but the rule checks for “Hello” with a capital H!

    Tier C — Accelerated · Grades 6–9
    🟣 Goal: Random replies + graceful fallback

    Use random.choice() so replies vary each time, and add a friendly “I don’t understand” fallback.

    Your checklist:

  • All Tier B goals complete
  • import random added at top
  • At least one keyword replies from a list of 3+ using random.choice()
  • Fallback message is friendly, not just "?"
  • Tested the same keyword 3 times to confirm replies vary

    • Code pattern:

    greetings = ["Hi!", "Hey there!", "Hello, friend!"]

    if "hi" in msg:
